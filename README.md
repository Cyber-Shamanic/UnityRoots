# 🇮🇱 UnityRoots (UR) — עם ישראל, שורשי האחדות

גרסה 0.0.2 · 5 בנובמבר 2026 · אור לכ״ו בחשוון תשפ״ז.

אתר סטטי עצמאי בעברית וב־RTL. **כל קובצי האתר — קוד, נתונים, תמונות PNG וגופני TTF — נמצאים ישירות בתיקיית השורש, בלי תיקיות משנה של נכסים**, כפי שהתבקש: `index.html`, `styles.css`, `app.js`, `chapters.js`, `vault.js`, `zip.js`, `CHANGELOG.md`, `TODO.md`, `s01.png`–`s24.png`, התמונות הראשיות והגופנים.

`dist/` הוא עותק בנייה טכני לפרסום בלבד. הסקריפט `build.mjs` מסנכרן את קובצי השורש לעותק הפרסום. אין צורך לשנות את הקבצים ב־`dist/` ידנית.

**הורדה ישירה:** האתר המפורסם כולל קובץ `UnityRoots_v0.0.2.zip` להורדת קובצי המקור והאיורים בפורמט PNG מותאם לאינטרנט. אפשר להוריד אותו דרך קישור בראש דף הבית ובתפריט הצד. לתיאור כלל התכולה, ראו גם `PROJECT_SUMMARY.md`.
ה־ZIP אינו מכיל עותק של עצמו; משום כך קישור הורדת ה־ZIP מיועד לאתר המפורסם, ולא לפתיחת קובץ `index.html` לאחר חילוץ החבילה במחשב.

## הפעלה

יש לשרת **את תיקיית השורש עצמה** בשרת HTTP סטטי רגיל (לדוגמה `python3 -m http.server 8000`). קובצי ה־Markdown נטענים באמצעות `fetch`, ולכן פתיחה ישירה ב־`file://` אינה תומכת בחלונות הגרסה וה־TODO בכל הדפדפנים.

## יכולות

- שבעת שערי הלב ו־70 פרקים מלאים, קלפי חזית/גב, ברכות, מפת מורשת וגלריית 24 סטיקרים שקופים.
- גלריית PNG עם הורדה פרטנית ו־ZIP של 24 הסטיקרים.
- ייצוא חזית וגב קלף כ־PNG עם עברית קריאה וממורכזת.
- כספת יצירות מקומית ב־IndexedDB: יצירה, עריכה, שכפול, תיוג, חיפוש, היסטוריה ושחזור.
- טעינת `CHANGELOG.md` וחלון גרסאות מעוצב.
- טעינת `TODO.md`, סינון ומד התקדמות.
- שמירה מקומית, חיפוש, מועדפים, העתקה, שיתוף, גיבוי JSON מורחב וייבואו.
- אפשרויות נגישות, תצוגה מותאמת לנייד וקישורי קרדיט.

## פרטיות וגבולות

מועדפים והעדפות נשארים ב־localStorage, ויצירות וגרסאות נשמרות ב־IndexedDB של הדפדפן. אין שרת משתמשים, כניסה ב־Google, טוקנים, או ניהול היסטוריית גלישה. אין להציג את כל אלה כפעילים עד למימוש אמיתי של שכבת זהות, הרשאות ושמירה מאובטחת.
