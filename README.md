# 🇮🇱 UnityRoots (UR) — עם ישראל, שורשי האחדות

גרסה 0.0.1 · 5 בנובמבר 2026 · אור לכ״ו בחשוון תשפ״ז.

אתר סטטי עצמאי בעברית וב־RTL. כל מה שנדרש להצגת התוכן נמצא ב־`dist/`: תכנים, תמונות רסטר מקוריות, גופנים מקומיים, CSS ו־JavaScript.

## הפעלה

יש לשרת את התיקייה `dist` בשרת HTTP סטטי רגיל (לדוגמה `python3 -m http.server 8000 --directory dist`). קובצי ה־Markdown נטענים באמצעות `fetch`, ולכן פתיחה ישירה ב־`file://` אינה תומכת בחלונות הגרסה וה־TODO בכל הדפדפנים.

## יכולות

- שבעת שערי הלב, קלפי השראה, ברכות, מפת מורשת וגלריית סמלים.
- טעינת `dist/CHANGELOG.md` וחלון גרסאות מעוצב.
- טעינת `dist/TODO.md`, סינון ומד התקדמות.
- שמירה מקומית, חיפוש, מועדפים, העתקה, שיתוף, גיבוי JSON וייבואו.
- אפשרויות נגישות, תצוגה מותאמת לנייד וקישורי קרדיט.

## פרטיות וגבולות

הנתונים האישיים נשארים ב־localStorage של הדפדפן. אין שרת משתמשים, כניסה ב־Google, טוקנים, או ניהול היסטוריית גלישה. אין להציג את כל אלה כפעילים עד למימוש אמיתי של שכבת זהות, הרשאות ושמירה מאובטחת.
